Deskripsi

Halaman About ini dibuat sebagai jawaban tugas praktikum untuk menampilkan satu layout berisi deskripsi, daftar kemampuan, dan portofolio sederhana. Struktur dibuat dengan elemen semantik agar mudah dibaca dan dikembangkan.

Tujuan proyek: mempraktikkan layout, box element, float dan clear, navigasi, widget sidebar, footer, serta desain responsif menggunakan media query.

Kemampuan yang Dipelajari

  • HTML5 Semantik
  • Box Model
  • CSS Float
  • Clearfix
  • Layout Sidebar
  • Responsive CSS
